# Play and run H&M Plus

Hearts and Minds Plus continues the original Hearts and Minds project with its own ongoing development. The root [README](../README.md) is the short feature overview; this page describes how the main features fit into a community's mission.

## What players use

- **Build and economy:** At an FOB, players use the ACE self-interaction **Build Menu** to place objects and purchase vehicles with shared mission funds. Salvaging eligible enemy vehicles returns funds. See [Build menu and vehicles](Add-vehicle-or-boat-to-H%26M-system.md).
- **Role arsenals:** The arsenal offers shared and role-specific equipment. Editors can customize the lists in `core/def/rolearsenal.sqf`; playable role descriptions must match. See [Arsenal and loadouts](ARSENAL-AND-LOADOUTS.md).
- **Permissions:** The in-game permissions interface manages access categories such as build, salvage, command, flight, and armour. See [Player permissions](PERMISSIONS.md).
- **Campaign progression:** Player actions and objective progress affect reputation and the mission economy. The mission includes side objectives and dynamic responses; see [Actions have consequences](Action-has-consequences.md) and [Mission parameters](PARAMETERS.md).
