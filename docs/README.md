# H&M Plus documentation

This documentation covers the public vanilla Hearts and Minds Plus mission. It is written for community owners, administrators, and mission editors who want to install, configure, and run their own server. The required mods are listed in the root [README](../README.md). Add optional map or faction mods only when your mission uses that content, and load them on server and clients.
